# ASCII 七並べ

## ゲームの概要

ターミナル上で遊ぶ、あなたとCPU 3人による七並べです。  
全52枚のトランプにジョーカー2枚を加えた54枚を使用し、手札を最初にすべて場へ出すと勝利です。

各マークの数字を7を基準に左右へ並べ、手札に出せるカードがない場合はパスします。

## 動作環境

- Windows 10 / 11
- Python 3.8以上
- ANSIカラー表示に対応したターミナル
- 外部ライブラリは不要

## インストール方法

Pythonをインストールした後、配布されたフォルダーを任意の場所に展開します。

追加ライブラリのインストールは不要です。

## 起動方法

ターミナルを開き、ゲームファイルがあるフォルダーへ移動します。

```powershell
cd C:\Users\Admin\Downloads\w14_ascii_seven_cards
python seven_card_5.py
```

## 操作方法

通常のカードは、次の形式で入力します。

```text
S6   スペードの6
H10  ハートの10
DA   ダイヤのA
CK   クラブのK
```

表示される `*` が付いたカードは、現在場に出せるカードです。

| 入力 | 動作 |
|---|---|
| `S6`、`H10`、`DA`など | 通常カードを出す |
| `JK S6`、`JK H10`など | ジョーカーを指定位置に置く |
| `P` または `PASS` | パスする |
| `Q` | ゲームを終了する |
| `Y` / `N` | 次の試合を開始するか確認する |

パスは1試合につき3回まで有効です。4回目のパスでドボンになり、そのプレイヤーは脱落します。

## 追加・改良した機能

### 改良機能01

ジョーカーを追加しました。ジョーカーは現在出せる通常カードの位置に置くことができ、場のジョーカーを覆ったカードを出すとジョーカーを手札へ回収できます。

### 改良機能02

パス上限とドボンを実装しました。4回目のパスで脱落し、残っていた通常カードは場に並べられます。ジョーカーはゲームから除外されます。

### 改良機能03

連戦機能と通算成績表示を追加しました。試合終了後に続けるか選べ、勝利数とドボン回数をプレイヤーごとに確認できます。

## 既知の問題・制限事項

- GUIではなく、文字入力による操作のみです。
- Windows以外のターミナルでは、ANSIカラー表示が正しく表示されない場合があります。
- CPUの思考はランダム選択で、難易度の設定や戦略の調整機能はありません。
- 通算成績はプログラム終了時にリセットされます。
- ターミナルの表示幅や文字サイズによっては、場のカードが見づらくなる場合があります。
